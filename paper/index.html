Machine Learning for Website Content Improvement

FlyRank ML Internship Capstone

Abstract

This project explores whether machine learning can help identify website pages that may benefit from content review. It uses page-level search performance data and compares a machine-learning approach with a baseline scoring method. Model performance is evaluated using a consistent validation design. The findings are interpreted in light of data limitations, possible leakage, and observed prediction errors. The resulting approach is intended to support human decision-making rather than guarantee improvements in website performance.
