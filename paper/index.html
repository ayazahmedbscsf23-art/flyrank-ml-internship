Machine Learning for Website Content Improvement

FlyRank ML Internship Capstone

Abstract

This project explores whether machine learning can help identify website pages that may benefit from content review. It uses page-level search performance data and compares a machine-learning approach with a baseline scoring method. Model performance is evaluated using a consistent validation design. The findings are interpreted in light of data limitations, possible leakage, and observed prediction errors. The resulting approach is intended to support human decision-making rather than guarantee improvements in website performance.

1. Introduction / Problem Statement

This project investigates whether page-level search performance data can help identify website pages that may benefit from content review. The central research question is: Can a machine-learning approach provide useful decision-support signals beyond a simple baseline scoring method? The project examines available features such as average search position, click-through rate (CTR), clicks, and impressions to explore patterns associated with content-review opportunities. Because these signals do not directly establish that a content update will improve performance, the model's outputs are treated as recommendations for further investigation rather than guaranteed outcomes..

3. Methodology

The methodology investigates whether page-level search performance features can support the identification of pages for further content review. Candidate features include average search position, click-through rate (CTR), clicks, and impressions, subject to verification against the available dataset. A baseline scoring method is used as a reference for evaluating the machine-learning approach. The target label is defined according to the project notebook and must represent the intended content-review opportunity without using future information or information derived directly from the outcome. Model evaluation should use the same evaluation split and metric for both the baseline and machine-learning model. Where appropriate, time-aware or client-grouped validation is used to reduce the risk of overly optimistic results. Features are also audited for target leakage, future-data leakage, and other information that would not be available when making a real decision..

4. Results

The evaluation compares the machine-learning model with the baseline scoring method using the same evaluation data and metric to support a fair comparison. The results should report the measured performance of each approach, the difference between them, and relevant error patterns. A separate validation audit examines how performance changes under a more realistic time-aware or client-grouped split. This comparison helps assess whether the original evaluation may have overstated generalization to unseen data. Charts and tables should be generated from the executed project notebooks and included only after their values have been verified. Until these measurements are added, no conclusion is made that the machine-learning model outperforms the baseline..

5. Limitations & Honest Framing

This project has several limitations. Page-level search performance metrics show associations and do not establish that updating content will cause better results. The quality of the findings depends on the dataset's coverage, the accuracy of the target-label definition, and the suitability of the validation design. Random splits may produce overly optimistic estimates when related pages or observations from the same client appear in both training and test data. Time-aware or client-grouped evaluation can provide a more realistic assessment, although it cannot eliminate every source of bias. Model predictions may also be affected by missing values, changes in search behaviour, and patterns not represented in the training data. Therefore, the model should be treated as a decision-support aid, and its recommendations should be reviewed by a human before action is taken.
